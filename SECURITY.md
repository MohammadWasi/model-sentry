# Security policy

Model Sentry fetches user-configured public URLs and can run in CI. Please do not report a suspected vulnerability, exploit details, private URLs, source snapshots, or credentials in a public issue.

Before the first public release, maintainers must enable GitHub private vulnerability reporting for the repository. Use that private reporting path for supported versions, include a minimal redacted reproduction, and allow time for a fix before public disclosure.

The first supported release line will be `0.1.x`. Security fixes will be released as a new patch version when practical.
